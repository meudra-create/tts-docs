# Charte graphique appliquée — Thème « Golden Hour »

Thème issu du skill **theme-factory** (anthropics/skills), choisi pour sa palette chaude
et automnale qui fait écho aux couleurs du Sahel : terre, soleil, dignité.

## Palette

| Rôle | Couleur | Hex |
|---|---|---|
| Texte courant, titres, ancres | Brun chocolat | `#4A403A` |
| Accent principal (filets, ornements, en-têtes d'encadrés) | Jaune moutarde | `#F4A900` |
| Sous-titres, citations, titres de partie | Terracotta | `#C1666B` |
| Fond des encadrés | Beige sable (éclairci `#F3EBDD`) | `#D4B896` |
| Texte des en-têtes d'encadrés | Crème | `#F4E9D6` |
| Attributions de citations | Brun grisé | `#8A7A6A` |

## Typographie

- **Titres et corps de texte** : FreeSans (police du thème).

## Application dans le livre

- **Titres de chapitre** : brun chocolat, soulignés d'un filet moutarde.
- **Titres de partie** : terracotta capitales, encadrés de deux filets moutarde, sur page neuve.
- **Sous-titres (H2)** : terracotta ; **H3** : brun chocolat.
- **Citations** : italique terracotta, barre d'accent moutarde à gauche ; **attributions** en brun grisé.
- **Encadrés** (anciens tableaux) : en-tête brun chocolat sur texte crème, corps sur fond beige clair.
- **Ornements de section** : fleuron ❦ moutarde.
- **Page de titre** : titre brun chocolat, filet moutarde, sous-titre terracotta.

Le rendu est disponible en `LIVRE-FINAL.pdf` (208 pages, format 6×9″) et `LIVRE-FINAL.docx`.
La version Markdown (`LIVRE-FINAL.md`) reste neutre : la charte est appliquée à l'export.
