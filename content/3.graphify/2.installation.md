---
title: Installation
description: Install Graphify and integrate it into your AI coding environment.
---

Graphify requires **Python 3.10+** and **Claude Code** (or another supported AI coding tool).

## Install via pip

```bash [terminal]
pip install graphifyy && graphify install
```

The `graphify install` step registers the `/graphify` slash command with your AI coding environment and installs required Python dependencies (`networkx`, `tree-sitter`, `whisper`, etc.).

::callout
---
icon: i-heroicons-light-bulb
---
Make sure you are running Python 3.10 or higher before installing. You can check with `python --version`.
::

## Verify Installation

Once installed, open a Claude Code session in any project directory and run:

```bash [terminal]
/graphify --version
```

You should see the installed version number printed to the terminal.

## Git Hook Integration

Graphify can automatically update your knowledge graph on every commit:

```bash [terminal]
graphify hook install
```

This installs a `post-commit` Git hook that re-runs Graphify incrementally so your graph stays in sync with your codebase.

To remove the hook:

```bash [terminal]
graphify hook uninstall
```

## Upgrading

```bash [terminal]
pip install --upgrade graphifyy && graphify install
```
