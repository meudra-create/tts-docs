Graphify is an AI coding assistant skill that reads your files, builds a knowledge graph, and gives you back structure you didn't know was there. It works inside Claude Code and other AI coding tools to help you understand codebases faster and uncover architectural relationships across any mix of file types.

## Features

- **Multimodal Input** - Processes code, PDFs, markdown, screenshots, diagrams, and video/audio files.
- **25 Language Support** - Parses source code via tree-sitter AST across 25 programming languages.
- **71.5x Token Reduction** - Achieves dramatic token compression per query compared to reading raw files on large corpora.
- **Transparent Relationships** - Tags all edges as `EXTRACTED`, `INFERRED`, or `AMBIGUOUS` with confidence scores.
- **Interactive Visualization** - Outputs an interactive HTML graph with search and filtering powered by vis.js.
- **No External Database** - Uses NetworkX and a local JSON graph — no database setup required.
- **Incremental Processing** - SHA256 file cache ensures only changed files are reprocessed on subsequent runs.

## Output Deliverables

Each run produces:

- **Interactive HTML graph** — browse and filter your knowledge graph visually
- **`GRAPH_REPORT.md`** — plain-language audit of discovered relationships
- **Persistent JSON graph** — reusable for future queries
- **Obsidian vault** — compatible with Obsidian for note-based exploration
- **Wikipedia-style articles** — generated summaries for key concepts

## Supported Platforms

Graphify works with Claude Code, Codex, OpenCode, Cursor, Gemini CLI, GitHub Copilot CLI, Aider, and more.
