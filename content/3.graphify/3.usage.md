## Analyze a Directory

Run Graphify on any folder from inside your AI coding tool:

```bash [terminal]
/graphify .
```

This analyzes the current directory using the default extraction mode and writes output artifacts to `.graphify/` inside the target folder.

### Modes

`--mode default` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Balanced extraction — suitable for most codebases.

`--mode deep` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Aggressive inference mode. Extracts more relationships at the cost of higher token usage and longer run times. Recommended for large, unfamiliar codebases.

```bash [terminal]
/graphify ./src --mode deep
```

## Watch Mode

Auto-sync the graph as files change:

```bash [terminal]
/graphify ./src --watch
```

Graphify watches the target directory for file changes and incrementally updates the graph in the background. Useful during active development sessions.

## Query the Graph

Once a graph has been built, you can ask semantic questions:

```bash [terminal]
/graphify query "what connects authentication to the payment module?"
```

Graphify uses the persistent JSON graph to answer queries without re-reading all source files, achieving the 71.5x token reduction advantage.

## Output Location

All artifacts are written to `.graphify/` inside the analyzed directory:

| File | Description |
|---|---|
| `graph.html` | Interactive visualization (open in browser) |
| `graph.json` | Persistent JSON graph for future queries |
| `GRAPH_REPORT.md` | Plain-language audit report |
| `obsidian/` | Obsidian vault with linked notes |
| `articles/` | Wikipedia-style generated articles |
| `.cache/` | SHA256 file cache for incremental runs |

## Understanding Edge Tags

Every relationship in the graph is tagged with a provenance label:

- **`EXTRACTED`** — directly derived from the file content (e.g. a function call, an import)
- **`INFERRED`** — logically inferred by the model based on context
- **`AMBIGUOUS`** — uncertain relationship included with a lower confidence score

Confidence scores range from `0.0` to `1.0` and are visible when hovering over edges in the HTML graph.
