## Slash Commands

All commands are invoked from inside your AI coding tool (e.g. Claude Code).

### `/graphify <path>`

Analyze a directory and build the knowledge graph.

```bash [terminal]
/graphify .                        # Current directory
/graphify ./src                    # Specific subdirectory
/graphify ./src --mode deep        # Deep inference mode
/graphify ./src --watch            # Watch mode (auto-sync)
```

**Options**

`path` [string · required]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Path to the directory to analyze. Use `.` for the current directory.

`--mode` [string · default: `default`]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Extraction mode. Accepted values: `default`, `deep`.

`--watch` [boolean]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Enable watch mode. Graphify will monitor the target directory and incrementally update the graph when files change.

---

### `/graphify query <question>`

Query the existing knowledge graph with a natural language question.

```bash [terminal]
/graphify query "what connects X to Y?"
/graphify query "which modules depend on the database layer?"
/graphify query "list all god nodes"
```

`question` [string · required]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

A natural language question about the codebase. Graphify uses the persistent `graph.json` to answer without re-reading source files.

## CLI Commands

The `graphify` CLI is available after installation for Git hook management and upgrades.

### `graphify install`

Register the `/graphify` slash command with your AI coding environment.

```bash [terminal]
graphify install
```

### `graphify hook install`

Install a `post-commit` Git hook to keep the graph in sync automatically.

```bash [terminal]
graphify hook install
```

### `graphify hook uninstall`

Remove the Git hook.

```bash [terminal]
graphify hook uninstall
```

### `graphify --version`

Print the installed version.

```bash [terminal]
graphify --version
```
