All API keys are subject to a rate limit of **200 requests per minute**. When this limit is exceeded the API returns `429 Too Many Requests` and no credit is charged.

## Rate Limit Headers

Every response includes rate limit information:

| Header | Description |
|---|---|
| `X-RateLimit-Limit` | Total requests allowed per minute |
| `X-RateLimit-Remaining` | Remaining requests in the current window |
| `X-RateLimit-Reset` | UTC epoch timestamp when the window resets |

When rate limited, the response also includes a `Retry-After` header indicating how many seconds to wait before retrying.

## Handling Rate Limits

When you receive a `429` response:

1. **Read the `Retry-After` header** and wait that many seconds before retrying.
2. **Use exponential backoff** if `Retry-After` is not present: wait 1 s, then 2 s, then 4 s, etc.
3. **Monitor `X-RateLimit-Remaining`** in your code to slow down proactively before hitting the limit.

### Example with Retry Logic

::code-group
```python [py]
import requests
import time

def get_transcript(video_url: str, api_key: str, retries: int = 3):
    url = "https://transcriptapi.com/api/v2/youtube/transcript"
    headers = {"Authorization": f"Bearer {api_key}"}
    params = {"video_url": video_url}

    for attempt in range(retries):
        response = requests.get(url, headers=headers, params=params)

        if response.status_code == 429:
            wait = int(response.headers.get("Retry-After", 2 ** attempt))
            time.sleep(wait)
            continue

        response.raise_for_status()
        return response.json()

    raise Exception("Max retries exceeded")
```

```ts [ts]
async function getTranscript(videoUrl: string, apiKey: string, retries = 3) {
  const url = 'https://transcriptapi.com/api/v2/youtube/transcript';

  for (let attempt = 0; attempt < retries; attempt++) {
    const res = await fetch(`${url}?video_url=${encodeURIComponent(videoUrl)}`, {
      headers: { Authorization: `Bearer ${apiKey}` },
    });

    if (res.status === 429) {
      const retryAfter = Number(res.headers.get('Retry-After') ?? 2 ** attempt);
      await new Promise((r) => setTimeout(r, retryAfter * 1000));
      continue;
    }

    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    return res.json();
  }

  throw new Error('Max retries exceeded');
}
```
::

## Best Practices

- **Cache responses** when possible to avoid redundant API calls.
- **Respect `Retry-After`** instead of using a fixed delay.
- **Do not retry** `400`, `401`, `402`, or `404` responses — they will not resolve by retrying.
- **Do not retry** more than 2–3 times within a short window for `408` or `503` errors.
