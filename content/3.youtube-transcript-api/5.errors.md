---
title: Errors
description: HTTP status codes, error response shapes, and retry guidance for the YouTube Transcript API.
---

The YouTube Transcript API uses standard HTTP status codes. Every unsuccessful response includes a `detail` field with a human-readable message and an optional machine-readable `code`.

```json [Error Response]
{
  "detail": "No transcript available for video ABC123XYZ",
  "code": null
}
```

## Status Codes

| Code | Meaning | Retry? |
|---|---|---|
| `200` | Success — transcript returned, 1 credit charged | — |
| `400` | Bad Request — invalid parameter combination | No |
| `401` | Unauthorized — missing or invalid API key | No |
| `402` | Payment Required — no active plan or no credits | No |
| `404` | Not Found — video/channel/playlist does not exist or has no transcript | No |
| `408` | Timeout — temporary failure (bot detection, network) | Yes, after 1–5 s |
| `422` | Validation Error — invalid URL or ID format | No |
| `429` | Too Many Requests — rate limit exceeded | Yes, after `Retry-After` |
| `500` | Internal Server Error | Maybe |
| `503` | Service Unavailable — temporarily down | Yes, after 1–5 s |

## Retryable vs Non-Retryable

**Retry these:**

- `408` — Wait 1–5 seconds and retry up to 2–3 times with exponential backoff.
- `429` — Wait the number of seconds in the `Retry-After` response header.
- `503` — Wait 1–5 seconds and retry.

**Do not retry these:**

- `400` — Fix the request parameters.
- `401` — Check your API key.
- `402` — Add credits or activate a plan.
- `404` — The resource does not exist or has no transcript.
- `422` — The URL or ID format is invalid; fix the input.

## Common Error Scenarios

### No transcript available

```json [404 Response]
{
  "detail": "No transcript available for video ABC123XYZ"
}
```

Some videos have captions disabled or are in a language not yet supported. There is no point retrying this request.

### Invalid video URL

```json [422 Response]
{
  "detail": "Invalid video URL or ID format"
}
```

The `video_url` parameter must be a full YouTube URL or a valid 11-character video ID.

### Credits exhausted

```json [402 Response]
{
  "detail": {
    "message": "You have an active plan, but you've run out of credits.",
    "reason": "insufficient_credits",
    "action_label": "Top up credits",
    "action_url": "https://transcriptapi.com/top-up"
  }
}
```

### Rate limited

```json [429 Response]
{
  "detail": "Too many requests"
}
```

Check the `Retry-After` header in the response and wait accordingly.

## Retry Strategy

For retryable errors (`408`, `429`, `503`):

1. Wait the recommended delay (`Retry-After` header or 1–5 seconds).
2. Retry with exponential backoff: 1 s → 2 s → 4 s.
3. Give up after 3 attempts and log the failure.
