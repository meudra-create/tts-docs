---
title: Credits & Billing
description: Understand how credits are consumed and what happens when they run out.
---

Requests to the YouTube Transcript API are billed in **credits**. Credits are deducted in real-time only when a request succeeds (HTTP 200). Failed requests are never charged.

## Credit Cost per Endpoint

| Endpoint | Credits per Request | Notes |
|---|---|---|
| `GET /api/v2/youtube/transcript` | 1 credit | Charged on successful 200 response |
| `GET /api/v2/youtube/search` | 1 credit | Per page |
| `GET /api/v2/youtube/channel/resolve` | **Free** | Requires auth + ≥ 1 active credit |
| `GET /api/v2/youtube/channel/search` | 1 credit | Per page |
| `GET /api/v2/youtube/channel/videos` | 1 credit | Per page (~100 videos) |
| `GET /api/v2/youtube/channel/latest` | **Free** | Requires auth + ≥ 1 active credit |
| `GET /api/v2/youtube/playlist/videos` | 1 credit | Per page (~100 videos) |

## When Credits Are Charged

| Response | Charged? |
|---|---|
| `200 OK` — successful response | Yes, 1 credit |
| `200 OK` — cached response | Yes, 1 credit |
| `4xx` / `5xx` error | No |
| `429` rate limited | No |

## Running Out of Credits

When your credit balance reaches zero, the API returns `402 Payment Required`.

**Exhausted credits on an active plan:**
```json [Response]
{
  "detail": {
    "message": "You have an active plan, but you've run out of credits.",
    "reason": "insufficient_credits",
    "action_label": "Top up credits",
    "action_url": "https://transcriptapi.com/top-up"
  }
}
```

**No active paid plan:**
```json [Response]
{
  "detail": {
    "message": "You don't have an active paid plan yet.",
    "reason": "no_active_paid_plan",
    "action_label": "Go to billing to choose a plan",
    "action_url": "https://transcriptapi.com/billing"
  }
}
```

::callout
---
icon: i-heroicons-light-bulb
---
Do not retry `402` responses — they will not resolve until you add credits or activate a plan.
::
