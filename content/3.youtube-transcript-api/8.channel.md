title: Channel

---

The channel endpoints let you work with YouTube channels: resolve handles to stable UC… IDs, list all uploads, search within a channel's content, and cheaply poll for new videos via RSS.

All channel endpoints accept a `channel` parameter that can be:
- An `@handle` (e.g. `@freecodecamp`)
- A channel URL (e.g. `https://www.youtube.com/@freecodecamp`)
- A `UC…` channel ID

---

## Resolve Channel

`GET https://transcriptapi.com/api/v2/youtube/channel/resolve`

Resolve any channel reference to a canonical `UC…` channel ID.

**Credit cost:** Free (requires auth and at least 1 active credit, but no credit is deducted).

### Query Parameters

`input` [string, required]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

`@handle`, channel URL, or `UC…` ID to resolve.

### Example Request

::code-group
```bash [terminal]
curl "https://transcriptapi.com/api/v2/youtube/channel/resolve?input=@freecodecamp" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python [py]
import requests

response = requests.get(
    "https://transcriptapi.com/api/v2/youtube/channel/resolve",
    params={"input": "@freecodecamp"},
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)
print(response.json())
```

```ts [ts]
import axios from 'axios';

const { data } = await axios.get(
  'https://transcriptapi.com/api/v2/youtube/channel/resolve',
  {
    params: { input: '@freecodecamp' },
    headers: { Authorization: 'Bearer YOUR_API_KEY' },
  }
);
console.log(data);
```
::

### Example Response

```json [Response]
{
  "channel_id": "UC8butISFwT-Wl7EV0hUK0BQ",
  "resolved_from": "@freecodecamp"
}
```

### Response Attributes

`channel_id` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The canonical `UC…` channel ID.

`resolved_from` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The original input value that was resolved.

## Channel Videos

`GET https://transcriptapi.com/api/v2/youtube/channel/videos`

Paginated list of all videos uploaded to a channel (~100 per page). Pass `channel` for the first page, then use `continuation` tokens for subsequent pages.

**Credit cost:** 1 credit per page.

### Query Parameters

`channel` [string, required for first page]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Channel identifier: `@handle`, channel URL, or `UC…` ID.

`continuation` [string, optional]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Pagination token from the previous response. When provided, `channel` is ignored.

### Example Request

::code-group
```bash [terminal]
# First page
curl "https://transcriptapi.com/api/v2/youtube/channel/videos?channel=@freecodecamp" \
  -H "Authorization: Bearer YOUR_API_KEY"

# Next page
curl "https://transcriptapi.com/api/v2/youtube/channel/videos?continuation=CONTINUATION_TOKEN" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python [py]
import requests

url = "https://transcriptapi.com/api/v2/youtube/channel/videos"
headers = {"Authorization": "Bearer YOUR_API_KEY"}

response = requests.get(url, headers=headers, params={"channel": "@freecodecamp"})
data = response.json()

# Iterate pages
while data["has_more"]:
    response = requests.get(url, headers=headers, params={"continuation": data["continuation_token"]})
    data = response.json()
```

```ts [ts]
import axios from 'axios';

const url = 'https://transcriptapi.com/api/v2/youtube/channel/videos';
const headers = { Authorization: 'Bearer YOUR_API_KEY' };

let { data } = await axios.get(url, { headers, params: { channel: '@freecodecamp' } });

while (data.has_more) {
  ({ data } = await axios.get(url, { headers, params: { continuation: data.continuation_token } }));
}
```

## Channel Search

`GET https://transcriptapi.com/api/v2/youtube/channel/search`

Search for videos within a specific channel (~30 results per page).

**Credit cost:** 1 credit per page.

### Query Parameters

`channel` [string, required for first page]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Channel identifier: `@handle`, channel URL, or `UC…` ID.

`q` [string, required for first page]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Search query.

`continuation` [string, optional]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Pagination token. When provided, `channel` and `q` are ignored.

### Example Request

::code-group
```bash [terminal]
curl "https://transcriptapi.com/api/v2/youtube/channel/search?channel=@freecodecamp&q=python" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python [py]
import requests

response = requests.get(
    "https://transcriptapi.com/api/v2/youtube/channel/search",
    params={"channel": "@freecodecamp", "q": "python"},
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)
print(response.json())
```

```ts [ts]
import axios from 'axios';

const { data } = await axios.get(
  'https://transcriptapi.com/api/v2/youtube/channel/search',
  {
    params: { channel: '@freecodecamp', q: 'python' },
    headers: { Authorization: 'Bearer YOUR_API_KEY' },
  }
);
console.log(data);
```

## Latest Channel Videos

`GET https://transcriptapi.com/api/v2/youtube/channel/latest`

Fetch the 15 most recent videos from a channel via YouTube's RSS feed. Returns exact publish timestamps and view counts.

**Credit cost:** Free (requires auth and at least 1 active credit, but no credit is deducted).

### Query Parameters

`channel` [string, required]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Channel identifier: `@handle`, channel URL, or `UC…` ID.

### Example Request

::code-group
```bash [terminal]
curl "https://transcriptapi.com/api/v2/youtube/channel/latest?channel=@freecodecamp" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python [py]
import requests

response = requests.get(
    "https://transcriptapi.com/api/v2/youtube/channel/latest",
    params={"channel": "@freecodecamp"},
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)
print(response.json())
```

```ts [ts]
import axios from 'axios';

const { data } = await axios.get(
  'https://transcriptapi.com/api/v2/youtube/channel/latest',
  {
    params: { channel: '@freecodecamp' },
    headers: { Authorization: 'Bearer YOUR_API_KEY' },
  }
);
console.log(data);
```

Number of videos returned (maximum 15).
