## Playlist Videos

`GET https://transcriptapi.com/api/v2/youtube/playlist/videos`

List all videos in a YouTube playlist, paginated (~100 per page). Pass a playlist URL or ID for the first request, then use the `continuation` token for subsequent pages.

**Credit cost:** 1 credit per page.

### Query Parameters

`playlist` [string, required for first page]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Playlist identifier: a YouTube playlist URL or a playlist ID starting with `PL`, `UU`, `LL`, `FL`, or `OL`.

`continuation` [string, optional]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Pagination token from the previous response. When provided, `playlist` is ignored.

### Example Requests

::code-group
```bash [terminal]
# First page by playlist URL
curl "https://transcriptapi.com/api/v2/youtube/playlist/videos?playlist=https://www.youtube.com/playlist?list=PLWKjhJtqVAbnRT_hue-3zyiuIYj0OlpyG" \
  -H "Authorization: Bearer YOUR_API_KEY"

# First page by playlist ID
curl "https://transcriptapi.com/api/v2/youtube/playlist/videos?playlist=PLWKjhJtqVAbnRT_hue-3zyiuIYj0OlpyG" \
  -H "Authorization: Bearer YOUR_API_KEY"

# Next page
curl "https://transcriptapi.com/api/v2/youtube/playlist/videos?continuation=CONTINUATION_TOKEN" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python [py]
import requests

url = "https://transcriptapi.com/api/v2/youtube/playlist/videos"
headers = {"Authorization": "Bearer YOUR_API_KEY"}
playlist_id = "PLWKjhJtqVAbnRT_hue-3zyiuIYj0OlpyG"

response = requests.get(url, headers=headers, params={"playlist": playlist_id})
data = response.json()

all_videos = data["results"]

while data["has_more"]:
    response = requests.get(url, headers=headers, params={"continuation": data["continuation_token"]})
    data = response.json()
    all_videos.extend(data["results"])

print(f"Total videos: {len(all_videos)}")
```

```ts [ts]
import axios from 'axios';

const url = 'https://transcriptapi.com/api/v2/youtube/playlist/videos';
const headers = { Authorization: 'Bearer YOUR_API_KEY' };
const playlistId = 'PLWKjhJtqVAbnRT_hue-3zyiuIYj0OlpyG';

let { data } = await axios.get(url, { headers, params: { playlist: playlistId } });
const allVideos = [...data.results];

while (data.has_more) {
  ({ data } = await axios.get(url, { headers, params: { continuation: data.continuation_token } }));
  allVideos.push(...data.results);
}

console.log(`Total videos: ${allVideos.length}`);
```

### Response Attributes

`results` [array]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Array of video objects in the playlist.

`results[].videoId` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

YouTube video ID.

`results[].title` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Video title.

`results[].channelId` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Uploader's channel ID.

`results[].channelTitle` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Uploader's channel display name.

`results[].channelHandle` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Uploader's channel handle.

`results[].lengthText` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Human-readable video duration.

`results[].viewCountText` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Human-readable view count.

`results[].thumbnails` [array]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Thumbnail objects with `url`, `width`, and `height`.

`results[].index` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

1-based position of the video within the playlist.

`playlist_info` [object | null]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Metadata about the playlist itself.

`playlist_info.title` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Playlist title.

`playlist_info.numVideos` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Total number of videos in the playlist.

`playlist_info.ownerName` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Display name of the playlist owner.

`continuation_token` [string | null]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Token to pass as `continuation` to fetch the next page. `null` when no more pages exist.

`has_more` [boolean]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Whether additional pages of results are available.

::callout

icon: i-heroicons-light-bulb

The `UU…` playlist ID is automatically created for every channel and contains all of that channel's public uploads. You can use it as an alternative to the `/channel/videos` endpoint.
