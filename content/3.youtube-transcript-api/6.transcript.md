## Get YouTube Transcript

`GET https://transcriptapi.com/api/v2/youtube/transcript`

Extract a YouTube video's transcript. Accepts a full YouTube URL or a bare 11-character video ID. Credits are charged only on success.

**Credit cost:** 1 credit per successful request.

### Query Parameters

`video_url` [string, required]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

YouTube video URL or bare 11-character video ID.

`format` [string, optional]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Output format. Either `json` (default) or `text`.

`include_timestamp` [boolean, optional]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Whether to include timestamps. Defaults to `true`.
- `json` + `true` → array of `{ text, start, duration }` objects.
- `json` + `false` → array of `{ text }` objects.
- `text` + `true` → timestamped lines: `[0.0s] text`.
- `text` + `false` → concatenated plain-text string.

`send_metadata` [boolean, optional]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Include basic video metadata (title, author, thumbnail). Defaults to `false`.

### Example Requests

::code-group
```bash [terminal]
# JSON with timestamps (default)
curl "https://transcriptapi.com/api/v2/youtube/transcript?video_url=dQw4w9WgXcQ" \
  -H "Authorization: Bearer YOUR_API_KEY"

# Plain text without timestamps
curl "https://transcriptapi.com/api/v2/youtube/transcript?video_url=dQw4w9WgXcQ&format=text&include_timestamp=false" \
  -H "Authorization: Bearer YOUR_API_KEY"

# JSON with metadata
curl "https://transcriptapi.com/api/v2/youtube/transcript?video_url=dQw4w9WgXcQ&send_metadata=true" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python [py]
import requests

url = "https://transcriptapi.com/api/v2/youtube/transcript"
headers = {"Authorization": "Bearer YOUR_API_KEY"}

# JSON with timestamps (default)
response = requests.get(url, headers=headers, params={"video_url": "dQw4w9WgXcQ"})

# Plain text without timestamps
response = requests.get(url, headers=headers, params={
    "video_url": "dQw4w9WgXcQ",
    "format": "text",
    "include_timestamp": False,
})

print(response.json())
```

```ts [ts]
import axios from 'axios';

const url = 'https://transcriptapi.com/api/v2/youtube/transcript';
const headers = { Authorization: 'Bearer YOUR_API_KEY' };

// JSON with timestamps (default)
const { data } = await axios.get(url, {
  headers,
  params: { video_url: 'dQw4w9WgXcQ' },
});

// Plain text without timestamps
const { data: text } = await axios.get(url, {
  headers,
  params: { video_url: 'dQw4w9WgXcQ', format: 'text', include_timestamp: false },
});

console.log(data);
```

### Example Responses

**JSON with timestamps (default):**
```json [Response]
{
  "video_id": "dQw4w9WgXcQ",
  "language": "en",
  "transcript": [
    { "text": "Never gonna give you up", "start": 0.0, "duration": 4.12 },
    { "text": "Never gonna let you down", "start": 4.12, "duration": 3.85 }
  ]
}
```

**JSON without timestamps (`include_timestamp=false`):**
```json [Response]
{
  "video_id": "dQw4w9WgXcQ",
  "language": "en",
  "transcript": [
    { "text": "Never gonna give you up" },
    { "text": "Never gonna let you down" }
  ]
}
```

**Text with timestamps (`format=text`):**
```json [Response]
{
  "video_id": "dQw4w9WgXcQ",
  "language": "en",
  "transcript": "[0.0s] Never gonna give you up\n[4.12s] Never gonna let you down"
}
```

**Text without timestamps (`format=text&include_timestamp=false`):**
```json [Response]
{
  "video_id": "dQw4w9WgXcQ",
  "language": "en",
  "transcript": "Never gonna give you up Never gonna let you down"
}
```

**With metadata (`send_metadata=true`):**
```json [Response]
{
  "video_id": "dQw4w9WgXcQ",
  "language": "en",
  "transcript": [...],
  "metadata": {
    "title": "Rick Astley - Never Gonna Give You Up",
    "author_name": "RickAstleyVEVO",
    "author_url": "https://www.youtube.com/@RickAstley",
    "thumbnail_url": "https://i.ytimg.com/vi/dQw4w9WgXcQ/hqdefault.jpg"
  }
}
```

### Response Attributes

`video_id` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The YouTube video ID.

`language` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Language code of the returned transcript (e.g. `en`).

`transcript` [array | string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The transcript data. An array of segment objects when `format=json`, or a plain string when `format=text`.

`transcript[].text` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The spoken text for the segment.

`transcript[].start` [number]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Start time of the segment in seconds. Present when `include_timestamp=true`.

`transcript[].duration` [number]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Duration of the segment in seconds. Present when `include_timestamp=true`.

`metadata` [object | null]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Basic video metadata. Only present when `send_metadata=true`.

`metadata.title` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Video title.

`metadata.author_name` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Channel name.

`metadata.author_url` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

URL to the channel page.

`metadata.thumbnail_url` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

URL to the video thumbnail image.
