## Search YouTube

`GET https://transcriptapi.com/api/v2/youtube/search`

Search YouTube for videos or channels. Returns approximately 20 results per page. Use the `continuation_token` in the response to fetch subsequent pages.

**Credit cost:** 1 credit per successful request (each page).

### Query Parameters

`q` [string, required for first page]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Search query. Required when fetching the first page. Omit when using `continuation`.

`type` [string, optional]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Result type. Either `video` (default) or `channel`.

`continuation` [string, optional]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Pagination token from a previous response. When provided, `q` and `type` are ignored — the token already encodes them.

### Example Requests

::code-group
```bash [terminal]
# Search for videos
curl "https://transcriptapi.com/api/v2/youtube/search?q=python+tutorial&type=video" \
  -H "Authorization: Bearer YOUR_API_KEY"

# Search for channels
curl "https://transcriptapi.com/api/v2/youtube/search?q=python+tutorial&type=channel" \
  -H "Authorization: Bearer YOUR_API_KEY"

# Next page using continuation token
curl "https://transcriptapi.com/api/v2/youtube/search?continuation=CONTINUATION_TOKEN" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python [py]
import requests

url = "https://transcriptapi.com/api/v2/youtube/search"
headers = {"Authorization": "Bearer YOUR_API_KEY"}

# First page
response = requests.get(url, headers=headers, params={"q": "python tutorial", "type": "video"})
data = response.json()

# Next page
if data["has_more"]:
    response = requests.get(url, headers=headers, params={"continuation": data["continuation_token"]})
    print(response.json())
```

```ts [ts]
import axios from 'axios';

const url = 'https://transcriptapi.com/api/v2/youtube/search';
const headers = { Authorization: 'Bearer YOUR_API_KEY' };

// First page
const { data } = await axios.get(url, {
  headers,
  params: { q: 'python tutorial', type: 'video' },
});

// Next page
if (data.has_more) {
  const { data: nextPage } = await axios.get(url, {
    headers,
    params: { continuation: data.continuation_token },
  });
  console.log(nextPage);
}
```

### Response Attributes

`results` [array]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Array of video or channel result objects depending on the `type` parameter.

`result_count` [integer]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Number of results in this page.

`continuation_token` [string | null]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Opaque token to pass as `continuation` to fetch the next page. `null` when there are no more pages.

`has_more` [boolean]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Whether additional pages of results are available.

#### Video Result Object

`videoId` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

YouTube video ID.

`title` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Video title.

`channelId` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

YouTube channel ID (`UC…`).

`channelTitle` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Channel display name.

`channelHandle` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Channel handle (e.g. `@freecodecamp`).

`channelVerified` [boolean]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Whether the channel is verified.

`lengthText` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Human-readable video duration (e.g. `4:26:52`).

`viewCountText` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Human-readable view count (e.g. `38M views`).

`publishedTimeText` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Human-readable publish time (e.g. `6 years ago`).

`hasCaptions` [boolean]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Whether the video has captions available.

`thumbnails` [array]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Array of thumbnail objects with `url`, `width`, and `height`.

#### Channel Result Object

`channelId` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

YouTube channel ID (`UC…`).

`title` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Channel display name.

`handle` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Channel handle (e.g. `@freecodecamp`).

`description` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Channel description.

`subscriberCount` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Human-readable subscriber count (e.g. `9.38M subscribers`).

`verified` [boolean]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Whether the channel is verified.

`rssUrl` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

URL to the channel's YouTube RSS feed.
