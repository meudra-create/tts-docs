The YouTube Transcript API gives you programmatic access to YouTube transcripts (captions), video search, channel data, and playlist listings. Responses are available in JSON or plain text, with optional timestamps and video metadata.

## Features

- **Transcript Extraction** — Retrieve full transcripts for any YouTube video with or without timestamps.
- **YouTube Search** — Search for videos or channels and paginate through results.
- **Channel Tools** — Resolve channel handles, browse uploads, search within a channel, and fetch the latest 15 videos for free via RSS.
- **Playlist Listings** — Paginate through all videos in any playlist.
- **Flexible Output** — Choose `json` or `text` format and control whether timestamps are included.

## Base URL

All endpoints are served from:

```
https://transcriptapi.com
```

## Quick Example

::code-group
```bash [terminal]
curl "https://transcriptapi.com/api/v2/youtube/transcript?video_url=dQw4w9WgXcQ&format=text&include_timestamp=false" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python [py]
import requests

response = requests.get(
    "https://transcriptapi.com/api/v2/youtube/transcript",
    params={"video_url": "dQw4w9WgXcQ", "format": "text", "include_timestamp": False},
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)
print(response.json())
```

```ts [ts]
import axios from 'axios';

const { data } = await axios.get(
  'https://transcriptapi.com/api/v2/youtube/transcript',
  {
    params: { video_url: 'dQw4w9WgXcQ', format: 'text', include_timestamp: false },
    headers: { Authorization: 'Bearer YOUR_API_KEY' },
  }
);
console.log(data);
```

## Endpoints Overview

| Endpoint | Method | Cost | Description |
|---|---|---|---|
| `/api/v2/youtube/transcript` | GET | 1 credit | Extract a video transcript |
| `/api/v2/youtube/search` | GET | 1 credit | Search videos or channels |
| `/api/v2/youtube/channel/resolve` | GET | Free | Resolve channel to UC… ID |
| `/api/v2/youtube/channel/search` | GET | 1 credit/page | Search within a channel |
| `/api/v2/youtube/channel/videos` | GET | 1 credit/page | Paginated channel uploads |
| `/api/v2/youtube/channel/latest` | GET | Free | Latest 15 videos via RSS |
| `/api/v2/youtube/playlist/videos` | GET | 1 credit/page | Paginated playlist videos |
