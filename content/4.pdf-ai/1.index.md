The PDF.ai API lets you upload PDF files and extract their content programmatically. You can control parsing quality, enable LLM-powered extraction, and specify the document language.

## Features

- **PDF Parsing** — Extract text and structure from any PDF document.
- **Quality Control** — Choose between `standard` and `high` quality parsing modes.
- **LLM Extraction** — Optionally use a large language model for smarter content extraction.
- **Multi-Language Support** — Specify one or more document languages for better accuracy.

## Base URL

```
https://pdf.ai
```

## Quick Example

::code-group
```bash [terminal]
curl -X POST https://pdf.ai/api/v2/parse \
  -H "x-api-key: YOUR_API_KEY" \
  -F "files=@document.pdf" \
  -F "quality=standard" \
  -F "llm=false" \
  -F "lang_list=en"
```

```python [py]
import requests

url = "https://pdf.ai/api/v2/parse"
headers = {"x-api-key": "YOUR_API_KEY"}
files = {"files": ("document.pdf", open("document.pdf", "rb"), "application/pdf")}
data = [
    ("quality", "standard"),
    ("llm", "false"),
    ("lang_list", "en"),
]

response = requests.post(url, headers=headers, files=files, data=data)
response.raise_for_status()
result = response.json()
print(result.get("success"), result.get("pageCount"))
```

```ts [ts]
const form = new FormData();
form.append('files', fs.createReadStream('document.pdf'), {
  filename: 'document.pdf',
  contentType: 'application/pdf',
});
form.append('quality', 'standard');
form.append('llm', 'false');
form.append('lang_list', 'en');

const response = await fetch('https://pdf.ai/api/v2/parse', {
  method: 'POST',
  headers: { 'x-api-key': 'YOUR_API_KEY', ...form.getHeaders() },
  body: form,
});
const result = await response.json();
console.log(result.success, result.pageCount);
```
