## Parse PDF

`POST https://pdf.ai/api/v2/parse`

Upload a PDF and extract its content. The request must be sent as `multipart/form-data`.

### Request Parameters

`files` [file, required]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The PDF file to parse. Must be sent as a multipart file upload with content type `application/pdf`.

`quality` [string, optional]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Parsing quality. Use `standard` for fast extraction or `high` for more thorough processing. Defaults to `standard`.

`llm` [boolean, optional]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Whether to use a large language model for smarter content extraction. Pass `true` or `false`. Defaults to `false`.

`lang_list` [string, optional]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Language code of the document (e.g. `en`, `fr`, `de`). Providing the correct language improves extraction accuracy.

### Example Request

::code-group
```bash [terminal]
curl -X POST https://pdf.ai/api/v2/parse \
  -H "x-api-key: YOUR_API_KEY" \
  -F "files=@document.pdf" \
  -F "quality=standard" \
  -F "llm=false" \
  -F "lang_list=en"
```

```python [py]
import requests

url = "https://pdf.ai/api/v2/parse"
headers = {"x-api-key": "YOUR_API_KEY"}
files = {"files": ("document.pdf", open("document.pdf", "rb"), "application/pdf")}
data = [
    ("quality", "standard"),
    ("llm", "false"),
    ("lang_list", "en"),
]

response = requests.post(url, headers=headers, files=files, data=data)
response.raise_for_status()
result = response.json()
print(result.get("success"), result.get("pageCount"))
```

```ts [ts]
import fs from 'fs';
import FormData from 'form-data';
import fetch from 'node-fetch';

const form = new FormData();
form.append('files', fs.createReadStream('document.pdf'), {
  filename: 'document.pdf',
  contentType: 'application/pdf',
});
form.append('quality', 'standard');
form.append('llm', 'false');
form.append('lang_list', 'en');

const response = await fetch('https://pdf.ai/api/v2/parse', {
  method: 'POST',
  headers: { 'x-api-key': 'YOUR_API_KEY', ...form.getHeaders() },
  body: form,
});

const result = await response.json();
console.log(result.success, result.pageCount);
```
::

### Example Response

```json [Response]
{
  "success": true,
  "pageCount": 5
}
```

### Response Attributes

`success` [boolean]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Whether the parse request was successful.

`pageCount` [integer]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Number of pages parsed from the uploaded PDF.

### Error Handling

| Status | Meaning |
|---|---|
| `200` | Success |
| `401` | Missing or invalid `x-api-key` |
| `400` | Bad request — check file format and parameters |
| `500` | Server error — retry after a short delay |

::callout
---
icon: i-heroicons-light-bulb

Call `response.raise_for_status()` (Python) or check `response.ok` (JavaScript) before reading the response body to surface HTTP errors early.
