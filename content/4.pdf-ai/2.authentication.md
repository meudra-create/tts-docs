title: Authentication

---

The PDF.ai API uses API keys to authenticate requests. Every request must include your API key in the `x-api-key` header.

## API Keys

Manage your API keys at [pdf.ai](https://pdf.ai).

::callout
---
icon: i-heroicons-light-bulb
---
Keep your API key secret. Never expose it in client-side code or public repositories. Load it from an environment variable or a secrets manager in your backend.
::

## Sending the Key

Include your API key in every request:

```
x-api-key: YOUR_API_KEY
```

### Example

::code-group
```bash [terminal]
curl -X POST https://pdf.ai/api/v2/parse \
  -H "x-api-key: YOUR_API_KEY" \
  -F "files=@document.pdf"
```

```python [py]
import requests

headers = {"x-api-key": "YOUR_API_KEY"}
files = {"files": ("document.pdf", open("document.pdf", "rb"), "application/pdf")}

response = requests.post("https://pdf.ai/api/v2/parse", headers=headers, files=files)
print(response.json())
```

```ts [ts]
const form = new FormData();
form.append('files', fs.createReadStream('document.pdf'), {
  filename: 'document.pdf',
  contentType: 'application/pdf',
});

const response = await fetch('https://pdf.ai/api/v2/parse', {
  method: 'POST',
  headers: { 'x-api-key': 'YOUR_API_KEY', ...form.getHeaders() },
  body: form,
});
```
