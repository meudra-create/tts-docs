The PDF Parsing API allows you to extract text content from PDF documents before converting them to speech. This is useful when you need fine-grained control over the parsed text prior to passing it to the TTS pipeline.

## Parse PDF
`POST https://pdf.ai/api/v2/parse`

This endpoint accepts a PDF file and returns the extracted text content along with metadata such as page count.

### Example Request
::code-group
```bash [terminal]
curl -X POST https://pdf.ai/api/v2/parse \
  -H "x-api-key: <your api key>" \
  -F "files=@/path/to/document.pdf" \
  -F "quality=standard" \
  -F "llm=false" \
  -F "lang_list=en"
```

```ts [py]
import requests

url = "https://pdf.ai/api/v2/parse"
headers = {"x-api-key": "<your api key>"}
files = {"files": ("document.pdf", open("document.pdf", "rb"), "application/pdf")}
data = [
    ("quality", "standard"),
    ("llm", "false"),
    ("lang_list", "en"),
]

response = requests.post(url, headers=headers, files=files, data=data)
response.raise_for_status()
result = response.json()
print(result.get("success"), result.get("pageCount"))
```

```ts [ts]
import axios from 'axios';
import FormData from 'form-data';
import fs from 'fs';

const url = "https://pdf.ai/api/v2/parse";
const form = new FormData();
form.append("files", fs.createReadStream("document.pdf"), "document.pdf");
form.append("quality", "standard");
form.append("llm", "false");
form.append("lang_list", "en");

axios.post(url, form, {
    headers: {
        "x-api-key": "<your api key>",
        ...form.getHeaders(),
    },
}).then(response => console.log(response.data));
```
::

### Request Attributes
<!-- space -->

`files` [string($binary)]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The PDF file to parse. Must be sent as `multipart/form-data`. The field name must be `files`.

`quality` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Parsing quality level. Accepted values are `standard` and `high`. The default value is `standard`.

`llm` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Whether to use LLM-assisted parsing for better accuracy on complex layouts. Pass `"true"` to enable or `"false"` to disable. The default value is `"false"`.

`lang_list` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The language of the document content as a BCP 47 language tag (e.g. `en`, `fr`, `de`). Providing the correct language improves extraction accuracy.

### Example Response
```json [Response]
{
  "success": true,
  "pageCount": 4,
  "pages": [
    {
      "page": 1,
      "text": "Lorem ipsum dolor sit amet..."
    },
    {
      "page": 2,
      "text": "Consectetur adipiscing elit..."
    }
  ]
}
```

### Response Attributes

`success` [boolean]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Indicates whether the request was successful.

`pageCount` [integer]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The total number of pages in the parsed document.

`pages` [array]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

An array of page objects containing the extracted text for each page.

`pages[].page` [integer]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The 1-based page number.

`pages[].text` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The extracted text content of the page.
