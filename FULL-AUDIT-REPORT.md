### 4.2 Critical Schema Issues

**BlogPosting → NewsArticle (Critical)**  
The site uses `BlogPosting` for all articles. For a news publication, `NewsArticle` is the correct type and is required to be eligible for Google News rich results and the Top Stories carousel. Fix in AIOSEO → Search Appearance → Content Types → Posts → Schema → change to `NewsArticle`.

**Duplicate BreadcrumbList (Medium)**  
Two BreadcrumbList schemas are being emitted on article pages: one from AIOSEO and one from the Newspaper theme. This is redundant and creates validation noise. Disable the theme's schema output.

**Generic Author Person schema**  
The `Person` schema for articles points to the `ndjonisangho` author profile with the display name "Ndjoni Sango". For E-E-A-T signals, each journalist should have their own author profile with `sameAs` links to professional profiles (LinkedIn, Twitter/X, etc).

**Missing `NewsMediaOrganization`**  
For news sites, AIOSEO can be extended with a `NewsMediaOrganization` schema type, which provides Google with additional trust signals about the publisher.

| Google Site Kit scripts | 4+ | ⚠️ Multiple event provider scripts |
| jquery-migrate | 1 | ⚠️ Outdated compatibility shim |

### 5.2 Key Performance Issues

**5× Duplicate AdSense Script** — `pagead2.googlesyndication.com/pagead/js/adsbygoogle.js` appears 5 times in the page source. This is likely caused by multiple ad units each loading the script independently. Use a single global `<script async>` include and configure ad slots without re-loading the library. This is a significant performance drag.

**jQuery Migrate** — `jquery-migrate.min.js` is loaded alongside jQuery 3.7.1. This backward-compatibility shim is only needed for very old plugins and adds unnecessary weight. Audit which plugins require it and update or replace them.

**Google Fonts blocking render** — Fonts from `fonts.googleapis.com` are loaded as `<link rel="stylesheet">` without `font-display: swap` or preload hints. This can block First Contentful Paint.

**Site Kit event providers** — Multiple Site Kit JS files are loaded for event tracking integrations (Mailchimp, OptinMonster, WPForms). Only keep integrations actively in use.

| Cyrillic filenames | Detected | ⚠️ `СВЛ_СиБиЭс.jpg` — non-ASCII filenames |

**45 empty alt attributes** on the homepage is a major accessibility and SEO failure. Most of these are article thumbnail images where AIOSEO/the theme is not propagating the image caption or filename as alt text. Fix by ensuring all uploaded images have alt text in the WordPress Media Library.

**Cyrillic image filenames** — Images uploaded from Russian-language sources retain Cyrillic filenames (e.g., `СВЛ_СиБиЭс.jpg`). Google cannot parse these filenames as keyword signals. Rename images to descriptive French/English slugs before uploading (e.g., `sergei-lavrov-ministre-affaires-etrangeres.jpg`).
